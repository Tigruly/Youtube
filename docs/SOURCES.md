# Каталог исходных материалов

Источник: [issue №1](https://github.com/Tigruly/Youtube/issues/1), проверено 2 октября 2026 года. ID T01–T42 и I01–I11 назначены по порядку вложений в issue; это **не номера «текст N» в названиях файлов**.

**Статус:** все 42 текстовых вложения прочитаны полностью, включая продолжения длинных файлов. Из них 29 — фрагменты переписки, 10 — файлы сценариев-референсов, 3 — тестовые документы. Две копии Taylor Swift (T17/T40) учитываются как один сюжетный референс, а не два независимых подтверждения.

Используются стабильные ссылки GitHub на вложения, а не временные подписанные адреса их хранилища. Оригиналы не дублируются в Git: они остаются во вложениях issue.
