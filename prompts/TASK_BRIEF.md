# Бриф на новый сценарий

Скопируйте блок, заполните известные поля и отправьте после [главного промпта](MASTER_PROMPT.md) или своему настроенному агенту. Неизвестное оставьте как «не задано». Не нужно придумывать данные ради заполнения формы.

```text
ЗАДАЧА
Тема / главный герой:
Канал / ближайший сценарий-референс:
Угол подачи: [необычные факты / опасные моменты / конфликты / эмоциональные истории / другое]
Рабочий английский заголовок:
Дата актуальности сведений:

ОБЪЁМ
Режим: [сбор фактов / скелет со вставками / тест / полный сценарий / переписывание / редакторская проверка]
Количество эпизодов в полном будущем ролике:
Что написать в этом ответе: [всё / интро + первые 3 / только эпизоды ...]
Нумерация и порядок: [обратный отсчёт / другое; порядок закреплён или можно предложить]
Кто пишет интро: [агент / заказчик / уже готово, не менять]
Целевая длительность готового ролика, включая вставки:
Для отдельного теста: [свой хронометраж / оценить только написанную часть]
Скорость нейроозвучки, если измерена:
Язык диктора: [по умолчанию английский]
Язык монтажных заметок: [по умолчанию русский]

ФАКТЫ И ИСТОЧНИКИ
Для каждого эпизода:
- Номер / рабочая тема:
- Что точно произошло:
- Когда / где / кто участвовал:
- Значимые числа и названия:
- Источник: [реальная ссылка или приложенный документ, дата публикации]
- Статус: [проверен по источнику / дан заказчиком, не проверен независимо / требует проверки]
- Что важно не перепутать / спорные сведения:
- Что должно произойти в развязке:

ВСТАВКИ
Для каждого клипа:
- К какому эпизоду относится:
- Реальный URL / приложенный файл:
- Диапазон: [начало - конец / НУЖЕН ТАЙМКОД]
- Откуда таймкод: [проверен по видео / дан в брифе / из транскрипта, требует видеопроверки]
- Роль: [вставка с оригинальным звуком / фон поверх диктора]
- Что зритель должен увидеть или услышать:
- Если исходный диапазон большой: целевая длительность после отбора:
- Права / разрешение на использование, если известно:

ПОДАЧА И МОНТАЖ
Степень драматизации: [только подтверждённые события и обоснованные ставки]
Юмор: [нейтральный / лёгкий мемный / конкретные разрешённые приёмы]
Запрещённые шутки / прозвища / формулировки:
Правила субтитров:
Правила цензуры:
Музыка / звуковые акценты / кредиты / другие требования:
Как заканчивается ролик: [диктор / последняя вставка без текста после неё / другое]

РЕФЕРЕНСЫ И ПРАВКИ
1–2 ближайших примера: [прикрепить тексты, а не только назвать файл]
Последние прямые замечания заказчика:
Если переписываем старую историю: [старый текст и что обновить; что нельзя менять]
Сохранять дословно: [указать только согласованные реплики, если есть]

НУЖНЫЙ РЕЗУЛЬТАТ
Основной результат: [монтажный сценарий / скелет / правки / другое]
Дополнительно: [чистый текст для TTS / факт-карта / подробный чек-лист / ничего]
Разрешён ли самостоятельный поиск новых источников: [да, если инструменты доступны / только мои материалы]
```

## Если нужно быстро поставить задачу

```text
Напиши [тест / полный сценарий] о [герой] на тему [угол].
Всего в будущем ролике [N] эпизодов; в этом ответе нужны [объём].
Интро [пишешь ты / пишет заказчик]. Длительность [диапазон], включая вставки.
Факты и клипы — ниже. Придерживайся прямых правок Martin, а не противоречащих им старых примеров.
Не выдумывай недостающие факты и таймкоды. Непроверенные места перечисли отдельно.
[Вставить факты, реальные ссылки, известные таймкоды и ограничения.]
```

## Для исходного теста про Billie Eilish

Из материалов следует объём **интро + первые три факта будущего ролика из 20**, то есть 20, 19 и 18: синдром Туретта, страхи, съёмка обложки в воде. Это отдельное тестовое задание, а не универсальный бриф на каждый следующий ролик. Ссылки на сам бриф и тестовые варианты — T14, T21, T39 в [каталоге](../docs/SOURCES.md). Утверждение о «шести часах полностью под водой» нельзя переносить в новый текст без проверки смысла исходной истории.
